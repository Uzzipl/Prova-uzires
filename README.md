# Prova-uzires

Projeto de estudo com uma aplicacao `Next.js` chamada `api-locadora`.

## Estrutura

- `api-locadora/`: aplicacao principal

## Objetivo

O projeto simula uma API simples de locadora, com CRUD de filmes e documentacao acessivel pelo navegador.

## Como executar

```bash
cd api-locadora
npm install
npm run dev -- --webpack
```

## Enderecos principais

- `http://localhost:3000`
- `http://localhost:3000/docs`
- `http://localhost:3000/api/filmes`
